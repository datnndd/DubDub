# Prompt Usage Instructions

## Subtitle Translation Prompts
	The `srt` directory contains prompts used when "Send Full Subtitles" is checked.
	The `text` directory contains prompts used when "Send Full Subtitles" is unchecked.

	{lang} is the target language variable, dynamically replaced; do not modify or delete.
	{context_block} is the original complete subtitle content, dynamically inserted or deleted based on selections in advanced options; do not manually modify.
	{GLOSSARY_DICT} is the glossary dictionary; do not modify or delete.
	{batch_input} dynamically inserts the subtitle content that needs translation; do not modify or delete.


## LLM Resegment Prompts
resegment directory --> llm.txt is the prompt for resegmenting with LLM after speech recognition. It may alter the timeline; modify according to actual needs, but note: NEVER alter the input requirements and return format requirements.
resegment directory --> llm2.txt is the prompt for resegmenting with LLM on recognition results after secondary recognition. It only corrects typos and does not alter the timeline.

## Gemini Speech Recognition Prompt

recogn directory --> gemini_recogn.txt is the prompt used when the speech recognition channel is set to GeminiAI speech recognition. It can be modified as needed, but note: NEVER alter the input requirements and return format requirements.
