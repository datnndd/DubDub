### Observation 2: Implemented Source Modifications in `webui.py`
1. **Import `math`**: Added `import math` at line 7.
2. **Dedicated `_safe_volume` Function** (lines 348–360):
   ```python
   def _safe_volume(value: Any, default: float) -> float:
       """Safely coerce volume float value clamped to [0.0, 1.5], with fallback default."""
       if value is None or isinstance(value, bool):
           return default
       try:
           val = float(value)
           if math.isnan(val):
               return default
           return max(0.0, min(1.5, val))
       except (TypeError, ValueError, OverflowError):
           return default
   ```
3. **Resilient `build_task_params`** (lines 495–585):
   - For `job_type == "render"`, `recogn_type` defaults to index 0 and default provider without requiring input from options.

   - Wrapped `raw_vol` float diff calculation in `try...except (OverflowError, ValueError)` to prevent `OverflowError`.
   - Mapped volumes using `_safe_volume(options.get("backgroundAudioVolume"), 0.8)` and `_safe_volume(options.get("originalAudioVolume"), 0.0)`.
4. **Hardened `edit_asset_handler`** (lines 800–845):
   - Explicitly rejects `application/x-www-form-urlencoded` requests with HTTP 400 Bad Request.
   - For non-multipart uploads, requires `X-Filename` header or query parameter, rejecting missing names with HTTP 400.
   - Rejects empty bodies and 0-byte uploaded files (`st_size == 0`), unlinking the empty file and raising HTTP 400.
