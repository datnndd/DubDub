## Executive Summary

This report delivers a thorough backend investigation of the DubDub AI Video Dubbing Studio (`pyvideotrans`) codebase in support of the **Stage 4: Edit Video** redesign. 

### Key Findings
1. **API Endpoints**:
   - `webui.py` uses `aiohttp.web` and exposes RESTful endpoints:
     - Media upload: `POST /api/media` (probes via `get_video_info` and stores in `MediaStore`).
     - Asset upload: `POST /api/assets/{kind}` (`kind` in `{"background-audio", "thumbnail"}`). Files are validated, stored in `UPLOAD_DIR`, and referenced by in-memory UUIDs in `EDIT_ASSETS`.
     - Export / Render pipeline: Executed via `POST /api/jobs` with `jobType: "render"`. There are currently no standalone `/api/export` or `/api/render` routes, but `POST /api/jobs` fully supports the Stage 4 render payload. Adding `/api/export` and `/api/render` as convenience aliases is recommended for API ergonomics.
2. **Audio Mixing Pipeline**:
   - Audio sources are separated into:
     - **Dubbed TTS Audio**: Controlled by `volume` (`"+0%"`, `"-20%"`, `"+50%"`, etc.), processed during TTS synthesis in `_stage_dubbing.py`.
     - **Background Music (BGM)**: Uploaded via `POST /api/assets/background-audio`, referenced by `backgroundAudioId` (mapped to `backgroundMusicPath`), adjusted with `backaudio_volume` (0.0 to 1.5), and mixed into `target.wav` in `AudioMixin._back_music()` via ffmpeg `amix`.
     - **Original Video Audio**: Controlled by `source_audio_volume` / `originalAudioVolume` (0.0 to 1.5) and mixed with `target.wav` in `AudioMixin._mix_original_audio()` via ffmpeg `amix`. When `0.0`, mixing is skipped (muted).
3. **Thumbnail Management**:
   - Uploaded via `POST /api/assets/thumbnail`, stored as an asset, and passed as `thumbnailId` (mapped to `thumbnailPath`).
   - If present, `_embed_thumbnail(task.cfg)` in `orchestrator.py` attaches the image as an MP4 `attached_pic` using stream copy (`-c copy -c:v:1 mjpeg`), embedding cover art into the final MP4 in milliseconds without re-encoding video streams.
   - When removed, `thumbnailId` is omitted, leaving the video container with its native default first frame.
4. **Subtitle Export & Styling**:
   - Stage 4 serializes edited segments into standard SRT syntax via `state.serializeEditedSrt()` and passes it in `options.subtitles`.
   - In `orchestrator.py`, receiving `subtitles` overrides transcript recognition and translation (`should_recogn = False`, `should_trans = False`), making Stage 4 edits authoritative.
   - Hard subtitle rendering uses `set_ass_font()` in `videotrans/util/_srt_ass.py`, applying dynamic styling parameters (`fontSize`, `fontFamily`, `color`, `outlineColor`, `outlineWidth`, `shadowSize`, `shadowColor`) converted directly into ASS style fields.

### 1.2 Analysis of `/api/export`, `/api/render`, `/api/upload`

- In the current implementation:
  - **Media Upload** is handled by `POST /api/media`.
  - **Asset Upload** (BGM and thumbnail) is handled by `POST /api/assets/{kind}` (`kind` = `background-audio` | `thumbnail`).
  - **Export and Render** are handled by `POST /api/jobs` with `payload.jobType = "render"`.
- Why `POST /api/jobs` is the unified task submission point:
  - `JobManager` tracks concurrency per media (`_active_by_media`), monitors worker threads, relays progress events (`EventKind.PROGRESS`, `EventKind.STAGE_STARTED`), and exposes progress/status polling at `GET /api/jobs/{job_id}`.
- **Recommendation**:
  For maximum client flexibility and compliance with conversational references:
  - Keep `POST /api/jobs` as the canonical implementation.
  - Optionally add routing aliases in `create_app()`:
    ```python
    app.router.add_post("/api/render", create_job_handler)
    app.router.add_post("/api/export", create_job_handler)
    app.router.add_post("/api/upload", media_handler)
    ```
    This ensures that any client calling `/api/render` or `/api/export` directly receives seamless execution.

## 2. Audio Mixing & Background Music Pipeline

### 2.1 Audio Source Separation & Parameters

Stage 4 separates audio into three distinct sources:

```
+-------------------------------------------------------------------------------+
|                             STAGE 4 AUDIO MIXING                              |
+-------------------------------------------------------------------------------+
| 1. Dubbed TTS Voiceover  -->  volume ("+0%", "-20%", "+50%", "-100%")         |
| 2. Background Music (BGM)-->  backaudio_volume (0.0 to 1.5, default 0.8)     |
| 3. Original Video Audio  -->  source_audio_volume (0.0 to 1.5, default 0.0)   |
+-------------------------------------------------------------------------------+
```

#### Mapping from Client to Task Parameters (`webui.py:545, 551-552`):
```python
"volume": str(options.get("volume") or "+0%"),
"backaudio_volume": max(0.0, min(1.5, float(options.get("backgroundAudioVolume", 0.8)))),
"source_audio_volume": max(0.0, min(1.5, float(options.get("originalAudioVolume", 0.0)))),
```

### 2.2 Dubbed Audio Synthesis & Volume Control (`videotrans/task/_stage_dubbing.py`)

1. During `TransCreate.dubbing()`, each subtitle cue is synthesized into a temporary WAV file in `queue_tts`.
2. The `volume` string is passed into each item: `tmp_dict["volume"] = self.cfg.volume`.
3. In `videotrans/tts/_base.py:243-272`, `volume` is parsed using regex:
   ```python
   volume = self.queue_tts[0].get('volume', '+0%')
   volume = f'+{volume}' if re.match(r'^\d+(\.\d+)?%$', volume) else volume
   self.volume = '+0%' if not re.match(r'^[+-]\d+(\.\d+)?%$', volume) else volume
   ...
   def get_volume(self) -> float:
       volume = 1.0
       if self.volume and self.volume != '+0%':
           volume = round(1 + float(self.volume.replace('%', '')) / 100, 1)
       return volume
   ```
4. TTS caching (`DUBBING_CACHE`):
   - Cache key is MD5 of `${target_lang}-${text}-${voice}-${rate}-${volume}-${pitch}-${tts_type}`.
   - If audio with identical text, voice, and volume already exists in cache, synthesis is bypassed and the cached `.wav` is copied immediately (`_stage_dubbing.py:83-86`).

### 2.3 Background Music (BGM) Execution (`videotrans/task/_stage_audio.py:15-49`)

```python
def _back_music(self) -> None:
    if self._exit() or not self.should_dubbing or not vail_file(self.cfg.target_wav) or not vail_file(self.cfg.background_music):
        return
    try:
        self.signal(text=tr("Adding background audio"))
        vtime = get_audio_time(self.cfg.target_wav)
        atime = get_audio_time(self.cfg.background_music)
        if atime < 1:
            return
        bgm_file = self.cfg.cache_folder + f'/bgm_file.wav'
        self.convert_to_wav(self.cfg.background_music, bgm_file, ["-filter:a", f"volume={self.cfg.backaudio_volume}"])
        self.cfg.background_music = bgm_file
        beishu = math.ceil(vtime / atime)
        if self.cfg.loop_backaudio and beishu > 1 and vtime - 1000 > atime:
            file_list = [self.cfg.background_music for n in range(beishu + 1)]
            concat_txt = self.cfg.cache_folder + f'/{time.time()}.txt'
            create_concat_txt(file_list, concat_txt=concat_txt)
            concat_multi_audio(
                concat_txt=concat_txt,
                out=self.cfg.cache_folder + "/bgm_file_extend.wav")
            self.cfg.background_music = self.cfg.cache_folder + "/bgm_file_extend.wav"

        cmd = ['-y',
               '-i', os.path.basename(self.cfg.target_wav),
               '-i', self.cfg.background_music,
               '-filter_complex', "[0:a][1:a]amix=inputs=2:duration=first:dropout_transition=2",
               '-ac', '2',
               '-c:a', 'pcm_s16le',
               "lastend.wav"
               ]
        runffmpeg(cmd, cmd_dir=self.cfg.cache_folder)
        self.cfg.target_wav = self.cfg.cache_folder + f"/lastend.wav"
    except Exception as e:
        logger.exception(f'添加背景音乐失败,静默跳过 {e}', exc_info=True)
```

### 2.4 Original Video Audio Mixing (`videotrans/task/_stage_audio.py:50-61`)

```python
def _mix_original_audio(self) -> None:
    volume = float(getattr(self.cfg, "source_audio_volume", 0.0) or 0.0)
    if volume <= 0 or not vail_file(self.cfg.source_wav) or not vail_file(self.cfg.target_wav):
        return
    mixed = self.cfg.cache_folder + "/target-with-original.wav"
    runffmpeg([
        '-y', '-i', os.path.basename(self.cfg.target_wav), '-i', os.path.basename(self.cfg.source_wav),
        '-filter_complex', f'[1:a]volume={volume}[original];[0:a][original]amix=inputs=2:duration=first:dropout_transition=2',
        '-ac', '2', '-c:a', 'pcm_s16le', os.path.basename(mixed)
    ], cmd_dir=self.cfg.cache_folder)
    self.cfg.target_wav = mixed
```

- When `source_audio_volume == 0.0`: The method returns immediately, leaving original audio muted.
- When `source_audio_volume > 0.0`: It applies ffmpeg `amix` to combine the scaled original audio with the dubbed/BGM mix.

### 2.5 Sequence in Assembly Stage (`videotrans/task/_stage_assemble.py:156-161`)

### 3.3 Lossless MP4 Cover Embedding (`videotrans/task/orchestrator.py:248-263`)

```python
def _embed_thumbnail(cfg: TaskCfgVTT) -> None:
    """Attach the selected cover image without re-encoding the rendered streams."""
    thumbnail = Path(cfg.thumbnail).resolve() if cfg.thumbnail else None
    video = Path(cfg.targetdir_mp4).resolve() if cfg.targetdir_mp4 else None
    if not thumbnail or not thumbnail.is_file() or not video or not video.is_file():
        return
    from videotrans.util.help_ffmpeg import runffmpeg
    staged = Path(cfg.cache_folder) / f"thumbnail-{video.name}"
    runffmpeg([
        '-y', '-i', video.as_posix(), '-i', thumbnail.as_posix(),
        '-map', '0', '-map', '1', '-c', 'copy', '-c:v:1', 'mjpeg',
        '-disposition:v:1', 'attached_pic', staged.as_posix(),
    ])
    if staged.is_file():
        staged.replace(video)
```
- **Performance**: Streams are copied (`-c copy`), avoiding full video re-encode.
- **Standard**: Follows MP4/MKV cover art specification (`-disposition:v:1 attached_pic`).
- **Reset/Default**: When `cfg.thumbnail` is None, `_embed_thumbnail` cleanly exits, allowing video players and file explorers to generate the preview from the first video frame.

## 6. Recommendations & Action Items

1. **Routing Resiliency**:
   - Provide route aliases `/api/render` and `/api/export` in `webui.py` pointing to `create_job_handler`, defaulting `jobType` to `"render"`.
   - Provide route alias `/api/upload` pointing to `media_handler`.
2. **Volume Format Normalization**:
   - In `webui.py:build_task_params`, normalize `volume`:
     If passed as float (e.g. `0.8`), convert to `f"{int(round((val - 1.0) * 100)):+d}%"` (e.g. `0.8` -> `"-20%"`).
     If passed as percentage string (e.g. `"-20%"`), accept directly.
3. **Multi-Speaker Line Roles Support in Render Payload**:
   - Allow `options` to accept `lineRoles: dict[str, str]` (mapping subtitle line numbers to voice roles) or `speakerVoiceMap`.
   - In `build_task_params`, assign `app_cfg.line_roles = options.get("lineRoles", {})` so that multi-speaker casting configured in Stage 3 is preserved when Stage 4 triggers re-dubbing.
4. **Thumbnail Image Format Compatibility**:
   - In `_embed_thumbnail`, if thumbnail is `.webp` or `.png`, ensure ffmpeg encodes image stream properly as `mjpeg` attached picture (`-c:v:1 mjpeg`). The current command `-c copy -c:v:1 mjpeg` handles this cleanly.
